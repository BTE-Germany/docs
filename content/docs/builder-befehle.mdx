Hier findest du zusätzliche Befehle und Werkzeuge, die dir als **Builder** zur Verfügung stehen.

> [!INFO]
> Die allgemeinen Befehle für Visitor stehen dir selbstverständlich ebenfalls zur Verfügung.

> [!IMPORTANT]
> Bau-spezifische Befehle und Werkzeuge können nur auf deinem Plot beziehungsweise in Bereichen verwendet werden, in denen du Baurechte besitzt.

## FastAsyncWorldEdit

Als Builder steht dir **FastAsyncWorldEdit (FAWE)** für umfangreiche Bearbeitungen zur Verfügung.

Eine vollständige Übersicht der verfügbaren Befehle findest du in der offiziellen FAWE-Dokumentation:

[FAWE Commands & Permissions](https://intellectualsites.gitbook.io/fastasyncworldedit/)

> [!NOTE]
> Nicht alle in der FAWE-Dokumentation aufgeführten Befehle sind zwangsläufig auf unserem Server verfügbar.

## Chat

| Befehl                | Alias | Beschreibung                                                        |
|-----------------------| --- |---------------------------------------------------------------------|
| `/channel global`     | — | Wechselt in den globalen Chat.                                      |
| `/channel builder`    | — | Wechselt in den Builder-Chat.                                       |
| `/ignore <Spieler>`   | — | Ignoriert Nachrichten des angegebenen Spielers.                     |
| `/ignorelist`         | — | Zeigt alle aktuell ignorierten Spieler an.                          |
| `/unignore <Spieler>` | — | Entfernt einen Spieler von deiner Ignore-Liste.                     |
| `/join <channel>`     | — | Tritt einen chat channel bei.                                       |
| `/leave <channel>`    | — | Verlässt einen chat channel. Du siehst davon keine nachrichten mehr. |

## Itemlinks

Du kannst Items aus deinem Inventar direkt im Chat verlinken.

| Slot | Platzhalter |
| --- | --- |
| Helm | `<helm>`, `<helmet>`, `<hat>`, `<head>` |
| Brustplatte | `<chest>`, `<chestplate>` |
| Hose | `<legs>`, `<leggings>` |
| Schuhe | `<boots>`, `<feet>` |
| Haupthand | `<main_hand>`, `<hand>`, `<item>` |
| Nebenhand | `<off_hand>` |


## Chat-Platzhalter

Im Chat stehen verschiedene Platzhalter für häufig benötigte Informationen zur Verfügung.

| Platzhalter | Beschreibung |
| --- | --- |
| `<info>` | Zeigt Informationen zu Lobby, Warps und `/tpll`. |
| `<plink>` | Zeigt einen Hinweis darauf, wo du die Links zu deinem Plot findest. |
| `<map>` | Verweist auf `map.bte-germany.de`. |
| `<mit>` | Erklärt kurz, wie du Builder werden kannst. |
| `<void>` | Erklärt, warum Visitor keine neuen Chunks laden können. |
| `<48h>` | Informiert über die mögliche Bewertungsdauer eines Plots. |
| `<prandom>` | Erklärt die zufällige Plot-Auswahl während der Übungsphase. |

## Axiom

Builder können **Axiom** als zusätzliches Bauwerkzeug verwenden.

Unter anderem stehen dir folgende Funktionen zur Verfügung:

- Angel Placement
- Fast Place
- Force Place
- Infinite Reach
- No Clip
- No Updates
- Phantom
- Replace Mode
- Tinker
- erweiterte Bewegungsgeschwindigkeit
- Axiom-Hotbar

> [!IMPORTANT]
> Axiom darf ausschließlich in Bereichen verwendet werden, in denen du Baurechte besitzt.

## Schematic Brush

Builder haben Zugriff auf zusätzliche Werkzeuge für Schematics und Brushes.

Dazu gehören unter anderem:

- Schematic Brushes
- Brush Presets
- Presets
- Tree Replace
- Wood Tools
- Brush Preview

## Weitere Builder-Befehle

| Befehl | Alias | Beschreibung |
| --- | --- | --- |
| `/hat` | — | Setzt das aktuell gehaltene Item als Kopfbedeckung auf. |
| `/phead <Spieler>` | — | Gibt dir den Spielerkopf des angegebenen Spielers. |
| `/secretblocks` | — | Öffnet beziehungsweise verwaltet spezielle Baublöcke. |
| `/noclip` | — | Aktiviert oder deaktiviert NoClip. |
| `/nv` | — | Aktiviert oder deaktiviert Night Vision. |
| `/banner` | `/bannermaker` | Öffnet den Banner-Maker. |
| `/advfly` | — | Aktiviert beziehungsweise verwaltet erweiterte Flugfunktionen. |
| `/accountlink` | — | Verknüpft deinen Minecraft-Account mit dem vorgesehenen Account-System. |
| `/speed` | — | Ändert deine Bewegungs- beziehungsweise Fluggeschwindigkeit. |
| `/gamemode` | — | Ermöglicht den Wechsel des Spielmodus im erlaubten Rahmen. |

## WorldEdit-Zusatzbefehle

| Befehl | Beschreibung |
| --- | --- |
| `//dell <Anzahl>` | Entfernt die letzten angegebenen Punkte aus der WorldEdit-Auswahl. |
| `//side` | Führt die entsprechende WorldEdit-Seitenfunktion aus. |
| `//cover` | Verwendet die WorldEdit-Cover-Funktion. |

> [!TIP]
> Mit der entsprechenden Berechtigung kannst du außerdem **F3 + N** verwenden, um zwischen Creative- und Spectator-Modus zu wechseln.
